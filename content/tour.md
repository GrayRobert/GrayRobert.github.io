# Tour

All the words in the guided tour, scene by scene, in the order they appear.

Each line is `- key: text`. Edit the text after the colon. Leave the key (the part before the colon) as it is, because that is how the tour finds the line. A line whose key starts with a robot's name (`ceo-`, `cto-`, `pm-` and so on) is something that robot says in a speech bubble. The rest are captions.

Captions wait long enough to be read, so longer text simply stays on screen longer.
